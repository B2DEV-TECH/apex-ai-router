# benchmark

Synthetic, Oracle/APEX-flavored benchmark harness comparing fixed-efficient,
fixed-capable, and `apex-auto` routing. Not implemented yet — planned for
Phase 8, after routing and telemetry exist. See root spec sections 26-29 and
51 for the task categories and scoring rules (deterministic scoring
preferred; LLM-judge scores reported separately and never hidden).

No results will be published in `results/` unless they come from an actual
measured run against real (or explicitly mock) providers, clearly labeled
which.
